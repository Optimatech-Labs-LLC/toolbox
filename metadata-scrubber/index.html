Metadata scrubber

Drop photos, PDFs or Office files. See what's hiding inside, GPS, camera serial numbers, author, revision history, comment authors, then download a clean copy. Nothing is re-encoded and nothing leaves your computer.

Inspect and clean

    What this does not do: it does not re-save or re-compress anything, so image quality is untouched. It cannot read metadata inside encrypted PDFs or inside compressed object streams in a PDF, and it says so when it meets one. HEIC photos are not supported yet.

    Where metadata hides

    JPEG   EXIF (camera, serial numbers, GPS, dates, thumbnail), XMP, IPTC, comments, data after the end marker
PNG    tEXt, zTXt, iTXt chunks (software, comments, XMP), eXIf, tIME
WebP   EXIF and XMP chunks
PDF    Document information (author, producer, dates), XMP metadata stream
Office docProps/core.xml and app.xml (author, company, revision), custom properties, thumbnail, comment and tracked-change authors
