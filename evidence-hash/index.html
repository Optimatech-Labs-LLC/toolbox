Evidence hash

Drop any file, any size. Get its SHA-256, and SHA-1 or MD5 if you need them, plus a receipt to attach to your report. The file is read on your computer and never leaves it.

Hash files

    The receipt records each file's name, size, hashes and the time on your computer's clock. It says so on the receipt. Nothing about you or your browser is included.

    Check a hash somewhere else

    Any of these produce the same SHA-256 for the same file. If they differ from this page, the file changed.

    macOS or Linux:   shasum -a 256 FILE
OpenSSL:          openssl dgst -sha256 FILE
Windows:          certutil -hashfile FILE SHA256
PowerShell:       Get-FileHash FILE -Algorithm SHA256
